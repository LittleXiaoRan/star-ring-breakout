# 星环突围 · STAR RING BREAKOUT

双摇杆竞技场射击：五波进攻 · 随机强化 · 动态首领。在失控星域中，杀出一条回路。

*A twin-stick arena shooter of waves and upgrades.*

**在线游玩：**

- GitHub Pages：https://littlexiaoran.github.io/star-ring-breakout/
- itch.io：https://littlexiaoran.itch.io/star-ring-breakout

## 玩法特色

- **波次战斗**：五波进攻 + 最终首领「星环监管者」（Ring Warden），全部目标清除后突围成功
- **三选一随机强化**：每波间隙构筑路线，不同搭配打出不同流派
- **相位冲刺**：冲刺期间穿越敌方弹幕；撞到敌人时双方都会受伤——冲刺有代价
- **地图机制**：六张星域地图各有独特地形与危险机制，波次与强化规则一致
  - 星港残骸：静态掩体，熟悉节奏
  - 回旋船坞：三圈旋转障碍
  - 熔炉核心：喷口全场喷射，隔热平台保命
  - 重力井：引力牵引与弯折弹道，传送门连接对角
  - 风暴航道：传送带与横扫能量墙
  - 霓虹矩阵：随机行列通电，无掩体挑战
- **限时强化**：地图上的强化点拾取即生效，持续几秒
- **双端操控**：键鼠与触屏均可完整游玩
- **中英双语**：游戏内一键切换
- **零依赖**：纯 HTML + CSS + 原生 JavaScript，无外部资源

## 操作

| 操作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左侧虚拟摇杆 |
| 瞄准射击 | 鼠标瞄准，按住左键射击 | 按住画面朝触点射击，拖动换方向，松手停火 |
| 相位冲刺 | Shift / 鼠标右键 | 右侧冲刺按钮 |

设置面板可开关自动射击、声音与语言。

## 文件结构

- `index.html` — 页面结构与游戏内 UI
- `style.css` — 全部样式
- `game.js` — 游戏逻辑
- `i18n.js` — 中英文文案

## 本地运行

直接双击打开 `index.html`，或启动本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000
